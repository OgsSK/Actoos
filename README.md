## 🚀 ACTOOS PRO

Application complète de gestion d'interventions pour entreprises de services.

| Composant | Technologie |
|-----------|-------------|
| Frontend | React 18 (PWA) + Tailwind + Shadcn/UI |
| Backend | FastAPI (Python) |
| Database | Supabase (PostgreSQL) |
| Paiements | Stripe |
| Emails | Resend |
