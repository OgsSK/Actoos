# ACTOOS - Plateforme de Gestion d'Interventions

Plateforme SaaS B2B pour la gestion d'interventions terrain en Europe.

## 📁 Structure du Projet

```
actoos/
├── actoos-pro/     # Application principale (Production)
├── actoos-one/     # Application secondaire (En pause)
└── vitrine/        # Site vitrine marketing
```

## 🚀 ACTOOS PRO (Principal)

Application complète de gestion d'interventions pour entreprises de services.

**Stack technique :**
- Frontend : React 18 (PWA) + Tailwind CSS + Shadcn/UI
- Backend : FastAPI (Python)
- Base de données : Supabase (PostgreSQL)
- Paiements : Stripe
- Emails : Resend

👉 **[Voir le guide de démarrage](./actoos-pro/README.md)**
